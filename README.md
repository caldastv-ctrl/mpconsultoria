# MPCONSULTORIA

Plataforma única para manejar empresas, contenido, diagnósticos, diseños, voces y videos.
Es un solo archivo (`index.html`): no necesita servidor, ni instalación, ni créditos.

## Publicarla gratis en GitHub Pages

1. Entra a github.com con la cuenta (o el correo) que quieras usar.
2. **New repository** → nombre `mpconsultoria` → **Public** → Create repository.
3. **uploading an existing file** → arrastra `index.html` y `README.md` → **Commit changes**.
4. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → **Save**.
5. En uno o dos minutos aparece la dirección: `https://TU-USUARIO.github.io/mpconsultoria/`

## Primer uso en la dirección nueva

Cada dirección web guarda sus propios datos. Una dirección nueva arranca vacía:

1. Abre la dirección y crea la **clave de acceso**.
2. **Ajustes → Restaurar respaldo** (o **Carpeta en la nube → Cargar el más reciente**).
3. **Ajustes → Conexión con Gemini**: pega tu clave de Google AI Studio.

## Actualizar

Descarga un respaldo, reemplaza `index.html` en el repositorio y recarga con Ctrl+F5.

## Contenido

- `index.html`: la plataforma completa.
- `docs/MPCONSULTORIA_ecosistema.xlsx`: seguimiento de módulos y etapas.

Este archivo no contiene claves ni datos de clientes. Tus datos viven en el navegador y en tus respaldos.
